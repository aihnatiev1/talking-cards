# FirstWords Cards — Spanish (es-419) Voiceover Script (v1, TTS-safe)

Format: each card has the WORD on its own line; the sentence follows on the next line.
Read the word clearly, then the sentence after a short pause (0.5–1.0 s).

File naming (mp3, matches the `audio` key in es_cards.json):
  <audio>.mp3 — word + pause + sentence (single clip, like uk/en)

NOTE: Neutral Latin American Spanish. No onomatopoeia — every
sentence is descriptive so TTS pronounces it naturally.
